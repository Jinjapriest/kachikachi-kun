# カチカチくん 設定推測

ジャグラー・ハナハナ（6号機以降）向けのデータカウンター兼設定推測アプリです。
スマホ1画面で、ボーナス・小役をタップして数えながら、設定1〜6の可能性をその場で計算します。

## 使い方

- **ブラウザで開く**：GitHub Pages を有効にすると `https://<ユーザー名>.github.io/kachikachi-kun/` で開けます。
- **ホーム画面に追加**：スマホで開いて「ホーム画面に追加」すると、アプリのように起動できます。一度開けば電波の弱いホールでも動きます（オフライン対応）。
- **ダウンロードして使う**：`index.html` をダウンロードしてブラウザで開くだけでも動きます（オフライン機能とホーム画面アイコンは GitHub Pages 経由のときのみ）。

## 推測のしくみ

各設定のボーナス・小役確率から、実測回数が出る確率（二項分布）を掛け合わせ、事前配分（初期値は均等）とあわせて設定ごとの確率を出しています（ベイズ推定）。

- ボーナス：台全体の総G数で計算
- 小役（ブドウ・チェリー・ベル）：自分の消化G数（総G − 打ち始めG）で計算
- 単独REG / チェリー重複REG：自分が引いたREGの内訳の比率で計算
- 確定演出：指定した設定未満を候補から外します

## 数値について

数値は解析サイトの公表値・調査値（ガリぞう氏の調査値など）です。小役確率は推定値を含むため目安としてお使いください。
ハナハナの小役（ベル・BIG中スイカ）は設定別の数値が公表されていないため、初期状態では推測に使いません。「数値」タブで入力すると反映されます。

データはお使いの端末のブラウザ内（localStorage）にだけ保存されます。
